# Wholesale Media panel prep

Mobile-first briefing page for Tareq's Tech for Retail panel in Paris: answers to Q1, Q2, Q4 and Q6, each with the question's intent, a short answer, a longer version, METRO angles and market context.

## Run locally
Open `index.html` in any browser. No build step.

## Publish with GitHub Pages
1. Create a repository and push these files to the `main` branch.
2. Go to Settings > Pages, choose "Deploy from a branch", then `main` and `/ (root)`.
3. The page goes live at `https://<your-username>.github.io/<repo-name>/`.

## Notes
- Fonts load from Google Fonts. Everything else is in `index.html`.
- METRO-specific points marked "Confirm" still need checking before the page is shared outside METRO.
- If the repository is public, anyone with the link can read the page.
